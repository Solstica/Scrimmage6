\section{模型总结与评价}

\subsection{模型总结}

本文围绕AI云数据中心异构GPU计算任务的调度与能源协同优化问题，建立了从数据驱动诊断到大规模联合优化的完整模型体系，形成以下四层递进结构：

\textbf{第一层（Q1）：统计预测与基础调度层。} 建立结构化标记复合泊松模型，通过到达过程诊断、业务组成诊断和条件资源诊断三层数据探针确定模型结构。该层不追求黑箱时序模型的表面精度增益，而是提供层级一致的需求分解、概率区间和可解释的计算侧基准。

\textbf{第二层（Q2）：计算任务柔性调度层。} 建立基于动态边际能源响应的0-1整数规划模型，并设计SFETA迭代收敛构造式启发式算法。通过基准能源错配审计识别出91.9\% region-hour“弃电与买电并存”的核心矛盾，以空间可行域数、时间余量、GPU-hour为排序键，在完整合法域上重排计算负荷，实现成本、碳排与新能源利用率的同步改善。

\textbf{第三层（Q3）：储能经济调度层。} 建立固定负荷下两阶段线性规划模型，先最小化净运行成本，再在成本最优面上最小化吞吐量。通过新能源盈余$H[r,t]$与售电限额$\text{SellLimit}[r]$的结构分析，自然识别出A/B/C、D/E、F三类储能角色，并用统一LP自动产生差异化策略，避免人为预设区域标签。

\textbf{第四层（Q4）：联合优化层。} 建立联合计算调度与能源调度的综合优化模型，提出Benders分解与精确列生成相结合的大规模求解框架。通过40-task exact benchmark验证顺序优化的失真性，确立联合优化的必要性。以Cost为第一字典序层，Wait与Latency在Cost最优面上逐层精化，避免主观多指标加权和。

\subsection{模型优点}

\begin{enumerate}
    \item \textbf{数据结构驱动建模}。四个问题的关键建模选择——Q1的泊松到达与联合业务标记、Q2的增量能量分段响应、Q3的区域角色分类、Q4的联合优化必要性——均由附件数据的可检验关系直接导出，而非预设模型强行套用。这种“诊断$\to$结构$\to$模型”的范式使模型复杂度与数据信息量相匹配。

    \item \textbf{双端点与字典序评价体系}。Q2采用Cost-primary与Carbon-primary双端点对照，避免人为Cost/Carbon权重和；Q4在Cost最优面上进行Wait/Latency字典序精化，使服务性能在成本最优集合内达到最优，而非牺牲经济性换取QoS。

    \item \textbf{完整域搜索与大规模求解的平衡}。Q2的SFETA算法保留完整$2.33\times10^8$合法候选域，通过构造式迭代收敛避免Top-k截断；Q4的Benders+CG框架进一步在50,000任务规模上实现了完整域LP定价闭合与最终扩展列池整数稳定，为大规模混合整数规划的近似最优解提供了结构化保证。

    \item \textbf{分层验证机制}。Q3的三层对照（B0/E0/E1）精确识别储能增量价值；Q4的40-task exact benchmark验证了列生成对完整域的等价性；硬约束审计与能量平衡残差检验贯穿全题，确保数值结果的物理一致性。
\end{enumerate}

\subsection{模型局限与改进方向}

\begin{enumerate}
    \item \textbf{预测模型的静态假设}。Q1的齐次泊松假设在24小时尺度上通过检验，但无法刻画更长时段的周周期或突发流量。后续可引入非齐次泊松过程或贝叶斯时变参数模型，并利用实时到达数据做在线更新。

    \item \textbf{构造式算法的全局最优性}。SFETA算法作为构造式启发式，虽通过多起点比较和收敛门禁提供了稳定代表解，但未提供与精确方法（如分支定界）的全局最优性边界。对于更大规模或更紧约束的场景，可进一步引入局部搜索或大邻域搜索增强。

    \item \textbf{储能模型未考虑退化与寿命}。Q3和Q4的储能调度以吞吐量最小化为次要目标间接控制使用强度，但未建立容量衰减与循环次数的显式模型。对于长期运行场景，应引入电池退化成本或寿命约束，避免频繁深度充放电。

    \item \textbf{碳排放的单边核算}。本文碳排放计算严格基于电网购电量的碳强度乘积，未考虑电力系统边际机组响应或绿证/碳交易机制。在碳市场环境下，可在目标函数中引入碳价格或碳预算约束，形成更丰富的Cost--Carbon权衡前沿。

    \item \textbf{三维仿真验证的时窗限制}。本问题中未设置类似转子发动机问题的COMSOL三维复核，若将模型扩展至包含服务器热力学或制冷系统动态，可采用“平均状态热力学模型+关键时窗CFD复核”的分层验证方法，进一步评估局部热点与制冷能耗的耦合效应。
\end{enumerate}

综上，本文所建模型在数据诊断、目标评价和求解策略上形成了完整闭环，为AI云数据中心的绿色调度提供了可量化、可追溯的数学工具。
