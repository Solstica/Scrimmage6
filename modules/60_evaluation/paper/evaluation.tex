\section{模型总结与评价}

\subsection{模型总结}

本文围绕AI云数据中心异构GPU任务调度与能源协同优化，建立了从数据驱动诊断到大规模联合优化的完整模型体系，形成以下四层递进结构：

\textbf{第一层（Q1）：统计预测与基础调度层。} 建立结构化标记复合泊松模型，通过到达过程、业务组成和条件资源三层诊断确定模型结构。该层提供层级一致的需求分解、概率区间和可解释的计算基准。

\textbf{第二层（Q2）：计算任务柔性调度层。} 建立基于动态边际能源响应的0-1整数规划模型，设计SFETA构造式启发式算法。通过能源错配审计识别91.9\% region-hour“弃电与买电并存”的核心矛盾，以空间可行域、时间余量、GPU-hour为排序键重排计算负荷，实现成本、碳排与新能源利用率同步改善。

\textbf{第三层（Q3）：储能经济调度层。} 建立固定负荷下两阶段LP模型，先最小化净运行成本，再在成本最优面上最小化吞吐量。通过新能源盈余$H[r,t]$与售电限额的结构分析，自然识别A/B/C、D/E、F三类储能角色，统一LP自动产生差异化策略。

\textbf{第四层（Q4）：联合优化层。} 建立计算与能源联合调度的综合优化模型，提出Benders分解与精确列生成相结合的大规模求解框架。通过40-task exact benchmark验证顺序优化的失真性，确立联合优化的必要性。以Cost为第一字典序层，Wait与Latency在Cost最优面上逐层精化，避免主观加权。

\subsection{模型优点}

\begin{enumerate}
    \item \textbf{数据结构驱动建模}。四个问题的关键建模选择——Q1的泊松到达与联合标记、Q2的增量能量分段响应、Q3的区域角色分类、Q4的联合优化必要性——均由附件数据可检验关系直接导出，模型复杂度与数据信息量相匹配。

    \item \textbf{双端点与字典序评价}。Q2采用Cost与Carbon双端点对照，避免人为权重和；Q4在Cost最优面上进行Wait/Latency字典序精化，使服务性能在成本最优集合内达到最优，而非牺牲经济性换取QoS。

    \item \textbf{完整域搜索与大规模求解平衡}。Q2的SFETA保留完整$2.33\times10^8$合法候选域，通过构造式迭代收敛避免Top-k截断；Q4的Benders+CG框架在50,000任务规模上实现完整域LP定价闭合与最终扩展列池整数稳定，为大规模MIP提供结构化保证。

    \item \textbf{分层验证机制}。Q3三层对照精确识别储能增量价值；Q4的40-task exact benchmark验证列生成对完整域的等价性；硬约束审计与能量平衡残差检验贯穿全题，确保数值物理一致性。
\end{enumerate}

\subsection{模型局限与改进方向}

\begin{enumerate}
    \item \textbf{预测模型的静态假设}。齐次泊松假设在24小时尺度上通过检验，但无法刻画更长时段的周周期或突发流量。后续可引入非齐次泊松过程或贝叶斯时变参数模型，并利用实时数据进行在线更新。

    \item \textbf{构造式算法的全局最优性}。SFETA作为构造式启发式，虽通过多起点比较和收敛门禁提供稳定代表解，但未提供与精确方法的全局最优性边界。对于更紧约束场景，可引入局部搜索或大邻域搜索增强。

    \item \textbf{碳排放单边核算}。碳排放计算基于购电量的碳强度乘积，未考虑边际机组响应或绿证/碳交易机制。碳市场环境下可在目标函数中引入碳价格或碳预算约束，形成更丰富的Cost--Carbon权衡前沿。
\end{enumerate}

综上，本文模型在数据诊断、目标评价和求解策略上形成完整闭环，为AI云数据中心绿色调度提供了可量化、可追溯的数学工具。
