# Q2 计算结果报告

状态：DRAFT / NEEDS_REVIEW

## 1. 模型与算法

模型采用 Q2_MODEL_SPEC.md 中的碳感知时空工作负载调度结构。决策变量为任务执行区域和整数小时开工时刻；储能 SOC、充放电、购售电策略保持附件基准，不作为 Q2 决策变量。

求解器为本文自定义的 SFETA 构造式启发式草稿。任务先按空间可行区域数、slack、GPU-hour 排序；候选位置按弃电缓解、碳强度、电价的字典序评价，并逐项检查 GPU-hour、IT、Facility、GridImport、SLA、deadline 和 2406 边界。结果是可行解，不是全局最优性证明。

## 4. 解释边界

当前模型规范尚未冻结 Cost-only 与 Carbon-only 极值探针，因此本结果只能作为 SFETA 字典序规则下的确定性可行解。论文若要写“最优”或正式冻结关键百分比，还需补充成本/碳极值或小规模精确解对照、目标顺序敏感性和等待时间约束敏感性。
