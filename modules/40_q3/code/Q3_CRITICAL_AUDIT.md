# Q3 批判性审核：固定负荷下 BESS 储能—新能源协同经济调度

状态：`DRAFT / NEEDS_REVIEW`

本审核针对当前 `Q3_MODEL_SPEC.md`，目的不是换模型，而是确认题意贴合、数据退化风险、B0/E0/E1 对照合理性与下一步轻量改进。

## 1. 题意贴合度

原题要求：在给定任务调度和逐时负荷基础上，建立储能协同优化模型，设计充放电策略，并分析运行成本、碳排放、区域峰值净购电功率和负荷波动程度。澄清进一步规定 Q3 固定 `Baseline_AI_IT_Load_MW` 与 `NonAI_IT_Load_MW`，只优化储能充放电、购售电与新能源分配，不重新优化任务迁移或开工时段。

当前模型与题意高度一致：固定负荷、释放能源侧变量、SOC 动态、购售电边界、成本主目标及多指标评价均直接对应题面。

### 必须修正的一处解释

“负荷波动程度”不能被静默改写成“NetGridImport 波动”。Q3 的 Facility Load 已被题面固定，因此：

1. **设施计算负荷波动**在优化前后严格不变，这是由题意直接决定的结果；
2. 为刻画储能对电网侧的平滑作用，可以**额外**报告 `NetGridImport` 的标准差/平均绝对爬坡，称为“电网交互功率波动”，但不能说它就是题面原词的唯一含义。

正文建议同时报告：

- `FacilityLoad` 波动变化率 = 0（固定负荷导致）；
- `NetGridImport` 波动变化，作为储能对外部电网影响的辅助指标。

## 2. 新能源过剩是否使模型太平凡

数据探针显示，除 RegionF 仅 1 个小时外，全部区域全部小时均有 `AvailableRenewable >= fixed FacilityLoad`。因此在允许重新分配新能源后：

- 无储能 E0 已几乎零购电/零碳；
- E1 可进一步做到零购电/零碳；
- A/B/C 在成本最优下甚至无需使用储能；
- D/E/F 的 BESS 价值主要来自跨时段新能源搬移与售电价格差，F 额外承担唯一新能源缺口小时的补偿。

这说明 **Carbon 与 PeakImport 在本数据下会发生显著退化**，但不意味着数学模型错误或过于简单。应把它作为数据结论，而不是人为增加权重、碳成本、退化成本或虚构新能源不足场景来制造冲突。

Q3 的非平凡部分仍然存在于：

- 2407 h SOC 跨时段耦合；
- 充放电效率与功率/容量边界；
- 售电上限与时变 Buy/Sell price；
- D/E/F 的跨时段新能源价值转移；
- 终端 SOC 约束；
- 六区域不同能源角色的自然分化。

因此当前模型可保留，但结果叙述应从“储能显著降碳”转向“在新能源极充足条件下，储能的边际价值主要体现为时移、售电套利和少量削峰”。

## 3. B0 / E0 / E1 是否合理

### B0：附件 raw baseline

合理，但只能作为“附件给定运行状态”或“原始参考状态”。D/E/F 的 `SOC(2406) < InitialSOC`，RegionE Hour 0 还有约 1 MWh SOC 单点不一致，因此 B0 不是 Q3 正式终端约束下的可行优化点。

结论：

- 可报告 `E1 - B0` 的原始结果差；
- **不得**把该差值全部解释为“储能优化收益”；
- 不建议用 B0 作为百分比最优性基准。

### E0：同口径无储能能源调度

合理，而且是当前最重要的消融/反事实对照。E0 与 E1 使用：

- 同一固定负荷；
- 同一 AvailableRenewable；
- 同一购售电价格与边界；
- 同一新能源分配自由度；

唯一差别是 `qR=qG=d=0`。

因此 `E1 - E0` 才能较干净地识别 BESS 的增量价值。

### E1：完整 BESS 协同调度

合理，是正式 Q3 解。

### 推荐解释

- `B0 -> E0`：附件原始能源运行状态与同口径无储能最优能源分配之间的“基准策略差距”；
- `E0 -> E1`：BESS 时移能力带来的“储能增量价值”；
- `B0 -> E1`：整体能源策略变化效果，仅作总体对比。

不要把 `B0 -> E0` 命名为“储能价值”。

## 4. 当前主目标是否合理

以运行成本最小为主目标是合理的：题目要求“分析”碳、峰值和波动影响，并没有要求四指标必须共同优化。当前数据又使 Carbon 几乎退化为零，因此强行构造多目标加权和缺少数据依据。

但需要新增一个探针：

- 在 `Cost = Cost*` 的最优面上，检查 PeakImport / NetGridImport 波动是否仍有明显可优化自由度。

若存在大量成本等价解，可考虑字典序：

1. `min Cost`；
2. 在成本最优集合内 `min PeakImport` 或 `min grid-interaction ramp`；
3. 最后 `min battery throughput` 排除无意义循环。

若成本最优解几乎唯一，则保持现有 `Cost -> Throughput` 两阶段结构，不额外增加层次。

该探针不使用权重，也不会改变主经济目标。

## 5. LP / MILP 判断

当前优先连续 LP 是合理的。主要非凸来源仅是“禁止同小时充放电”的互补关系，而附件本身未要求显式二元状态变量。

现有两阶段做法：

1. 求成本最优；
2. 在成本最优集合内最小化总充放电吞吐量；

在现有数据探针中可以消除同时充放电，因此暂不需要约 6×2407 个充放电状态二元变量。

但必须把这件事当作结果门禁，而不是理论上自动保证：若正式求解后仍出现显著 SCD，则采用有理论依据的 complementarity exact-relaxation / penalty 方法，最后才升级 MILP。

## 6. 六区域可分解性

当前模型没有跨区电力交换、共享 SOC、统一碳预算或系统峰值耦合约束。因此可行域是六区域可行域的笛卡尔积，目标是区域成本之和：

`min sum_r Cost_r = sum_r min Cost_r`。

把 Q3 分成 6 个独立区域 LP 是严格数学分解，不是近似，也不是人为简化。该性质应在论文中明确写出，既减少计算量，也帮助解释六区储能角色不同。

## 7. 不建议加入的复杂机制

当前不建议：

- stochastic programming / DRO：题目给的是实际逐时数据，不需要预测不确定性；
- MPC：离线全时域参数已知，MPC 的在线滚动优势用不上；
- RL / ADP / GA / PSO：没有必要牺牲可解释性和可验证性；
- 电池 SOH/退化成本：附件没有循环寿命、DoD-aging、SOH 或 replacement cost 参数；
- 共享储能/Stackelberg/博弈：题目没有共享储能运营商与价格博弈主体；
- 线路潮流：题面明确不建跨区线路模型。

## 8. 审核结论

当前 Q3 主模型无需推翻。推荐继续使用：

**固定负荷下的多时段 BESS economic dispatch / optimal dispatch**。

正式求解前只需完成三项修正/探针：

1. 负荷波动指标区分“Facility Load 固定不变”和“NetGridImport 辅助波动”；
2. B0 明确降级为 raw reference，E0 才是储能增量价值的正式无储能对照；
3. 检查成本最优面上是否可无成本进一步削峰/平滑，再决定 Stage 2 是 `Peak/Ramp -> Throughput` 还是直接 `Throughput`。
