## Q1 总体结构（已统一）

问题一不是单独一个预测模型，而是三个连续任务：

1. **Q1-1：不同区域、不同 TaskType 的 GPU 需求统计分析**；
2. **Q1-2：基于统计结构的 24 h 短期 GPU 需求概率预测**；
3. **Q1-3：2376--2399 h 实际到达任务的基础算力调度，并输出甘特图和区域 GPU 利用率**。

三者的逻辑是：

`统计结构识别 -> 短期需求预测 -> 实际任务进入基础运行机制 -> GPU 利用率`。

Q1-1 **不是重新分类**。`TaskType` 与 `SourceRegion` 已由附件给定；本部分通过描述统计、关联检验和条件关系检验提取数据结构，并直接为 Q1-2 的概率分解提供依据。

Q1 不建立多目标优化模型，不设置主观权重，不把电价/碳/新能源作为基础调度依据；这些因素从 Q2 起进入。Q1-2 的预测只用于独立评价，Q1-3 直接使用 2376--2399 的真实到达任务，预测误差不传入后续调度。

- [x] Q1-1 不是分类模型；Region 与 TaskType 标签已知，统计分析用于提取结构并为 Q1-2 提供概率分解依据。
- [x] Q1 不是 SFETA/REPTA 优化问题；它是“统计结构识别 + 短期预测 + 基础调度机制”。
