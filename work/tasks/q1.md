## Q1 总体结构（已统一）

问题一包含三个连续任务：

1. **Q1-1：不同区域、不同 TaskType 的 GPU 需求统计分析**；
2. **Q1-2：基于统计结构的 24 h 短期 GPU 需求概率预测**；
3. **Q1-3：2376--2399 h 实际到达任务的基础算力调度，并输出甘特图和区域 GPU 利用率**。

逻辑链：`统计结构识别 -> 短期需求预测 -> 实际任务进入基础运行机制 -> GPU 利用率`。Q1-1 不是分类问题；`TaskType` 与 `SourceRegion` 已由附件给定。Q1-2 预测只用于独立评价，Q1-3 直接使用 2376--2399 h 的真实到达任务。Q1 不建立多目标优化模型，不把电价、碳、新能源作为基础调度依据。

## 数据结构驱动的模型表达（论文必须保留）

- 到达统计支持近齐次 Poisson，而弱 ACF/季节性验证不支持为了复杂度引入 LSTM/ARIMA；
- `TaskType × SourceRegion` 明显相关，因此采用联合业务标记 `pi_rk`；
- 给定 TaskType 后 Region 对 GPU/Duration 的附加影响弱，因此资源 mark 按 TaskType 条件化；
- GPU 与 Duration 不强行独立，保留联合经验 mark；
- 因而 Q1 的模型顺序必须写成 `到达过程诊断 -> 业务组成诊断 -> 条件资源诊断 -> 标记复合 Poisson`，不能从“选用某模型”起笔。

文献与可引用边界见 `Q1_DATA_DRIVEN_MODELING_AND_LITERATURE.md`。

## 已确定的数据与模型判断

- 小时总任务到达近 Poisson，均值约 20.8，Fano 约 0.97，lag 1/24/168 自相关很弱。
- TaskType×SourceRegion 存在明显结构关系，因此使用联合标记 `pi_rk`，不拆成 `P(R)P(K)`。
- 给定 TaskType 后，Region 对 GPU_Demand 和 Duration 的附加影响较弱；GPU 与 Duration 相关接近 0 不能升级为严格独立，因此保留联合经验 mark。
- Q1-2 的系统层点预测与历史均值相同是模型结构的自然结果；其附加价值来自底层一致分解与概率预测，不应包装成系统点预测精度提升。
- 修正版 Test 90% PICP：Region×TaskType 约 94.21%、Region 约 89.58%、TaskType 约 90.28%、System 87.5%；System 仅 24 点，不能据此回调模型。
- Q1 不是 SFETA/REPTA 优化问题；Q1-2 是短期基线预测，Q1-3 是实际任务基础调度。
- 时间语义：到达止于 2399，2400--2405 为 drain，2406 仅终端能源结算且禁止计算任务占用。
