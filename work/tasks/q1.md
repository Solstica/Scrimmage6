## 已确定的数据与模型判断

- [x] Q1 不是 SFETA/REPTA 优化问题；它是“统计预测 + 基础调度机制”。
- [x] 1 h × 0--2399 只有约 2400 个时间观测，不属于高频长历史时序；复杂 LSTM/DGLM/季节模型没有数据依据时不启用。
- [x] 小时总任务到达近 Poisson：均值约 20.8333、Fano≈0.9687，lag 1/24/168 自相关很弱。
- [x] TaskType×SourceRegion 存在明显结构关系，因此 `(Region,TaskType)` 使用联合标记 `pi_rk`。
- [x] `GPU_Demand ⟂ SourceRegion | TaskType` 初步成立：三类 GPU×Region 检验 p 约 0.535/0.776/0.146，区域解释方差 η² < 0.001。
- [x] `Duration ⟂ SourceRegion | TaskType` 初步成立：三类 Kruskal-Wallis p 约 0.329/0.790/0.142，η² < 0.0005。
- [x] 主 GPU mark 使用 TaskType 条件经验分布；离散均匀只作简化对照。
- [x] Gamma-Poisson / Dirichlet Bayesian 更新不作为主模型必需部分；若后续需要参数不确定性/企业在线更新再扩展。
- [x] 预测对象锁定为“每小时新到达任务的 GPU_Demand 总量”；GPU-hour 只作工作量补充。
- [x] Q1 最后24 h正式调度使用 2376--2399 实际到达任务，预测误差不进入调度或 Q2--Q4。
- [x] baseline 机制已识别为“SourceRegion + ArrivalHour 到达即执行”，并能重构附件 baseline AI IT load。
- [x] 时间语义：到达止于 2399；2400--2405 为 drain；2406 仅终端能源结算且禁止计算任务占用。
