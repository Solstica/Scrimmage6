## Q3 当前定位

问题三严格固定 `Baseline_AI_IT_Load_MW` 与 `NonAI_IT_Load_MW`，设施负荷按

`L[r,t] = PUE[r] * (Baseline_AI_IT_Load_MW[r,t] + NonAI_IT_Load_MW[r,t])`

计算；不重新优化任务迁移与开工时段。

主模型：**固定负荷下的 BESS 储能—新能源协同经济调度**。数学主体优先采用两阶段字典序 LP：先最小运行成本，再在成本最优集合内最小储能吞吐量，去除多重最优中的无意义同时充放电循环。

### P1 决策变量与平衡
- [ ] 每个 `(r,t)` 建立 `u` 直接新能源、`qR` 新能源充电、`qG` 电网充电、`d` 放电、`gL` 电网供负荷、`s` 新能源售电、`w` 弃电、`E` SOC。
- [ ] `AvailableRenewable = u + qR + s + w`。
- [ ] `Load = u + d + gL`。
- [ ] `GridPurchase = gL + qG`。
- [ ] `ChargePower = qR + qG`。
- [ ] `GridSell=s` 仅允许来源于新能源分配；不得把网购电或储能放电直接转成售电。

### P2 SOC 与硬约束
- [ ] `E[-1]=InitialSOC`。
- [ ] `E[t]=E[t-1]+eta_c*(qR+qG)-d/eta_d`。
- [ ] SOC 上下限；总充电功率上限；放电功率上限。
- [ ] `GridPurchase<=MaxGridImport`。
- [ ] `s<=min(SellLimit,MaxGridExport)`。
- [ ] `E[2406]>=InitialSOC`。
- [ ] Hour 2406 的电力/储能结算计入真实成本和碳，不允许免费补终端 SOC。

### P3 主目标与多重最优处理
- [ ] Stage 1：最小化 `sum(Price*GridPurchase - SellPrice*GridSell)`。
- [ ] Stage 2：在 `Cost<=Cost*+tolerance` 下最小化 `sum(qR+qG+d)`。
- [ ] Stage 2 后检查同小时充放电必须为 0（容差内）。
- [ ] 若仍存在显著同时充放电，再回交建模手决定是否加 MILP 二元互斥；不要一开始就上 MILP。
- [ ] 不构造 Cost/Carbon/Peak/Fluctuation 的主观加权和。

### P4 三层对照（强制）
- [ ] `B0`：附件 raw baseline。
- [ ] `E0`：同一固定负荷、同一新能源/购售电自由度，但 `qR=qG=d=0` 的无储能最优能源调度。
- [ ] `E1`：完整 BESS 协同调度。
- [ ] `E1-E0` 才解释为储能增量贡献；`E1-B0` 只能解释为整体能源策略优化效果。

### P5 指标
- [ ] 运行成本：官方购电成本减售电收益。
