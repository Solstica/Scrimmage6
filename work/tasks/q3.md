### P1 决策变量与平衡
- [ ] 每个 `(r,t)` 建立 `u` 直接新能源、`qR` 新能源充电、`qG` 电网充电、`d` 放电、`gL` 电网供负荷、`s` 新能源售电、`w` 弃电、`E` SOC。
- [ ] `AvailableRenewable = u + qR + s + w`。
- [ ] `Load = u + d + gL`。
- [ ] `GridPurchase = gL + qG`。
- [ ] `ChargePower = qR + qG`。
- [ ] `GridSell=s` 仅允许来源于新能源分配；不得把网购电或储能放电直接转成售电。

### P3 主目标与成本最优面探针
- [ ] Stage 1：最小化 `sum(Price*GridPurchase - SellPrice*GridSell)`。
- [ ] 不构造 Cost/Carbon/Peak/Fluctuation 的主观加权和。
- [ ] 在 `Cost<=Cost*+tolerance` 的成本最优面上，检查 PeakImport / NetGridImport ramp / battery throughput 是否仍有显著改善自由度。
- [ ] 若存在明显自由度，采用无权重字典序：`Cost -> Peak/Ramp -> Throughput`。
- [ ] 若不存在明显自由度，保持 `Cost -> Throughput` 两阶段结构。
- [ ] 不为显示多目标而人为制造 Pareto 前沿。
