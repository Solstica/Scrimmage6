## 已锁定模型：不再换模型族

Q2 仍为 **Carbon-Aware Spatiotemporal Workload Scheduling**。

模型链：

`任务时空决策 -> AI IT -> Facility Load -> 基准状态增量能源响应 -> Cost / Carbon / Renewable utilization`。

固定边界：

- 决策变量只有任务执行区域与开工时刻；BESS/SOC/GridSell 等能源动作留给 Q3/Q4；
- 完整合法 `(task,region,start)` 域，不使用 top-k、最近区域或人为 24h/48h 最大等待窗；
- RT：`StartHour=ArrivalHour`，空间枚举全部 SLA 合法区域；
- Batch/Training：完整整数 start domain，满足 Arrival/EarliestStart、LatestFinish 与 2406；
- priority：`RegionCount 小 -> Slack 小 -> GPU-hour 大`；
- 候选按当前排程状态计算 `DeltaCurtailment / DeltaGridPurchase / DeltaCost / DeltaCarbon`；
- 等价候选 tie-break：更早开工 -> SourceRegion -> 更低 latency；
- Cost/Carbon 不使用人工加权和。
