## 已锁定模型，不再换模型族

Q2 仍为 **Carbon-Aware Spatiotemporal Workload Scheduling**。决策变量只有任务执行区域与开工时刻；储能充放电、GridSell 等能源动作在 Q2 固定为附件基准状态，把储能自由度留给 Q3/Q4。

模型链：

`任务时空决策 -> AI IT -> Facility Load -> 基准状态增量能源响应 -> Cost / Carbon / Renewable utilization`。

保留：

- 完整合法 `(task,region,start)` 域，不设置 top-k、24h 最大等待窗或最近区域裁剪；
- RT：`StartHour=ArrivalHour`，空间域为全部 SLA 合法区域；
- Batch/Training：完整整数 start domain，满足 Arrival/EarliestStart、LatestFinish 与 2406；
- priority：`RegionCount 小 -> Slack 小 -> GPU-hour 大`；
- 候选使用当前排程状态的 `DeltaCurtailment / DeltaGridPurchase / DeltaCost / DeltaCarbon`；
- 等价候选 tie-break：更早开工 -> SourceRegion -> 更低 latency；
- Cost/Carbon 不使用主观加权和。
