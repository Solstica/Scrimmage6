## 已确定判断

- [x] Q2 主体属于 `carbon-aware spatiotemporal workload scheduling`；该术语由 EuroSys 2024 等文献直接支持。
- [x] `spatiotemporal flexibility` 与 `renewable curtailment mitigation` 均为文献中真实使用的术语；不是本文造词。
- [x] `resource-constrained scheduling`、`time-indexed formulation`、`marginal resource allocation` 均为成熟术语，但本题无 precedence graph，因此不直接称 RCPSP。
- [x] SFETA 是本文自定义算法名，不包装成标准算法。
- [x] 完整 `(task,region,start)` 合法候选约 `2.33e8`，需要结构化构造算法，但不得人为截断合法域。
- [x] RT 时间/空间柔性显著小于 Batch/Training；Training GPU-hour 最大，支持基于可行域与 slack 的 priority rule。
- [x] 六区域 AvailableRenewable 逐时相同，不能作为空间迁移优势来源；Curtailment0 有强空间差异，可作为 baseline 的 renewable curtailment mitigation 裕量。

- [x] Cost/Carbon/Renewable utilization 由同一增量能量平衡链重算；CarbonIntensity 不允许退化成纯后验评价。
