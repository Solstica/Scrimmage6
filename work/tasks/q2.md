## 已确定的数据与模型判断

- [x] Q2 显式决策变量是任务执行 Region 与 StartTime；储能控制不属于 Q2 主决策。
- [x] Q2 数学本体属于资源约束的离散时空组合调度；时空图可用于表示合法域，队列状态可用于解释等待，但不另立图论/排队论主模型。
- [x] SFETA 是求解算法，不是目标函数或模型名称。
- [x] 完整合法 `(task,region,start)` 候选约 `2.33e8`，确实需要结构化构造算法，但合法域不得人为截断。
- [x] RT 时间/空间柔性显著小于 Batch/Training；Training 的 GPU-hour 最大，支持 least-flexible-first + resource-heavy tie-break。
- [x] 六区域 `AvailableRenewable_MW` 逐时完全相同，不能作为空间迁移优势来源。
- [x] `Curtailment_MW` 存在强空间差异，且与 CarbonIntensity 显著负相关；应作为 Q2 基准状态中的主要新能源边际机会量。
- [x] 直接自由重分配 AvailableRenewable 会构造出 50000/50000 可行且 GridPurchase=0、Carbon=0 的退化解，因此排除该能源解释。
- [x] 已冻结基准状态中心化边际能源核算：任务调度改变 Facility Load；baseline storage/market flows 固定；负荷增量先吸收 Curtailment，再进入 GridToLoad。
- [x] 附件统一口径要求 `MaxGridImport_MW/MaxGridExport_MW` 为区域硬约束；Q2 读取边界参数但不释放储能/市场策略为决策。
- [x] Cost/Carbon/Renewable utilization 由同一能量守恒链重算，不使用互不相干的评分函数。
- [x] 题面 CarbonIntensity 按附件统一公式直接用于碳核算；不自行替换为文献中的 marginal carbon intensity。

## 文献审查后采用的建模原则

- [x] REPTA (Applied Energy 2026)：保留“利用 delay tolerance 缩减巨大时空组合搜索 + 非迭代领域规则分配”的思想。
- [x] EuroSys 2024 carbon-aware shifting：任务长度、deadline/SLO 与时空柔性决定可减碳空间；复杂策略常只有有限增益，因此本题保持简单、可解释的结构规则。
- [x] CarbonScaler (POMACS 2023)：吸收“marginal resource allocation”思想；SFETA 比较任务放置造成的边际 Cost/Carbon，而不是给 Region 做静态绝对评分。
- [x] GREEN (NSDI 2025)：碳强度应作为调度信号，同时守住时间效率/容量约束；本题已有实际逐时信号，不再引入预测层。
- [x] INFORMS JOC 2021 epsilon-constraint：若 Cost 与 Carbon 真有 Pareto 冲突，可无权重地处理离散多目标；只有极值探针确认冲突后才启用。
